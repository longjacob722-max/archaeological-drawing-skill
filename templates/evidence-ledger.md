# 考古器物绘图证据账本模板

> 每次绘图、审图或数字化任务复制一份填写。未知项写“未知/待实测”，不能用器类常识替代。

## 1. 任务与对象

- 任务类型：制图 / 学习分析 / 审查 / 数字化
- 材质标签：
- 器物形态标签：
- 器名、标本号、出土单位/地点：
- 成品状态：照片证据转译稿 / 实测图 / 结构分析稿 / 待复核

| 文件/编号 | 观察方向 | 原图/成品身份 | 是否含可靠尺寸 | 透视、镜像、遮挡风险 |

## 3. 证据分层

| 直接可见 | 多视角/测量共同支持 | 未知、遮挡或不可辨 |
|---|---|---|
|  |  |  |

## 4. 表面与结构判定

- 表面异物层（锈蚀、铜绿、包浆、污渍、斑驳、颗粒、反光）：
- 结构性痕迹（轮廓、转折、孔洞、断口、缺蚀边界、纹饰、工艺痕）：
- 异物层下可辨纹饰：逐段记录位置、方向、端部、叠压和断失；不可辨处：
- 明确排除项（背景、支撑物、尺子、米格线、修复材料等）：

## 5. 视图、剖面与尺寸

- 视图集合及每幅图要解决的信息缺口：
- 共同基准/中心轴/底线：
- 剖面形式与真实切面依据：
- 可靠尺寸、单位、来源和支持的视图：
- 比例尺：有 / 无；若无，原因：

## 6. 纹饰与工艺层

- 纹饰分区、单元数量、方向、疏密、连接、叠压、不对称：
- 陶瓷釉线、釉/露胎边界、流釉/积釉及釉面纹饰：
- 转折线、圈足/底足、器壁厚度、断口和真实缺损：
- 表现决策：线 / 点 / 黑面 / 留白 / 断线；每项证据：

## 7. 交付与复核

- SVG：有 `viewBox`；无 `<image>`/`data:image`；文字标注可编辑：是 / 否
- PNG：由最终 SVG 回渲染；与原照片逐段核对：是 / 否
- 线例：用户/项目要求时提供；否则默认不提供
- 待复核区域及原因：
- 审核人/日期：
