# 传统器物线图学习包（整合版）

本文件整合 `traditional_artifact_line_drawing_pack.zip` 中的 8 个文件：手册、分材质技法、标准速查、工具与流程、审图清单、30 天练习计划、标准与书目、README。它是 `archaeological-artifact-drawing` 的 supporting reference；需要传统手工流程、分材质画法、训练或完整审图时读取。

## 0. 核心规则指向

本包不重复定义总硬规则。所有流程均须先遵守主 [SKILL.md](../SKILL.md) 的证据优先级、纹饰优先合同和比例尺触发规则；本包只补充传统手工、分材质、训练与扩展资料。腐蚀/铜绿若有保存或研究价值，另用照片、文字、病害图或专题记录表达，不塞进结构线图。

## 1. 学习包的使用顺序与证据层级

### 推荐顺序

1. 先读本文件第 0—5 节，确定证据、投影、比例、线型和纹饰画法；
2. 按器物材质读取第 6 节；
3. 按第 7—8 节完成实测、铅笔起稿、墨线和数字化复制；
4. 用第 9 节逐项审图；
5. 需要训练时执行第 10 节 30 天计划；
6. 需要追溯来源时查第 11 节。

### 资料层级标签

| 标签 | 含义 | 使用方式 |
|---|---|---|
| [硬标准] | 现行标准或正式项目要求 | 优先执行原文 |
| [项目体例] | 发掘、整理、博物馆或期刊的统一规定 | 整组图一致 |
| [专业惯例] | 多个专业体系常用的画法 | 不冒充强制标准 |
| [经验技巧] | 为提高准确性、可读性和复现性总结的方法 | 与实物和项目要求核对 |
| [必须核实] | 通用规则无法决定的对象事实 | 回到实物、影像、专家或修复记录 |

冲突判断顺序：文物本体安全 → 项目设计书/委托方体例 → 现行标准 → 器物专家/绘图负责人 → 专业惯例 → 经验技巧。

## 2. 动笔前的器物证据表

至少记录：器物编号、出土单位/收藏号、材质与器类、保存状态、允许接触区域、方向/主轴、拟定主视、最终用途、最终版面尺寸、比例、总体尺寸、关键尺寸、孔径/孔道、壁厚/底厚/沿厚、纹饰位置、残损、修复/补配、照片编号、可见证据、推定内容、复原内容、不确定问题、测量人/日期、复核人/日期。

把每个判断标为：

- **实测**：由直尺、卡尺、分规或测点直接得到；
- **可见**：照片、放大观察或实物能确认；
- **推定**：由对称、同类器或工艺逻辑推断；
- **复原**：由断口、镜像、拼合或资料恢复；
- **不确定**：证据不足，只保留现状或不确定标记。

先看总体形制，再看结构，最后看表面。照片用于核对，不替代实测；单张透视照片只能支持“照片证据转译稿/待实物复核”，不能虚报为精确实测图。

## 3. 视图、投影、比例和线型

投影、比例尺、线宽、线型和剖面条款以 [规制参考](field-drawing-rules.md) 为准。本包只强调执行顺序：先用能完整表达对象的最少视图和共同基准，再处理结构、纹饰、材质和版式；不得为排版随意旋转、镜像或把透视效果当成实测图。关键尺寸、最终缩印和比例尺的判断按主 skill 与规制参考执行。

## 4. 纹饰绘制协议（重点）

### 4.1 四层顺序

1. **布局层**：中心、轴线、带宽、边界、分区、方向和重复关系；
2. **形制层**：母题外缘/内缘、转折、起止、穿插、端部和叠压；
3. **技术层**：刻、划、印、压、铸、錾、磨、堆塑等可核实痕迹；
4. **损伤层**：缺失、磨损、断裂和被覆盖的范围，按现状表达。

不要一上来描花纹而失去轴线和比例。纹饰重复不等于几何复制；先找母题起止、中心和变体。

### 4.2 锈蚀覆盖下的模糊纹饰

- 连续的浮雕边缘、沟槽或刻线：画清楚的细线；
- 走向连续但局部模糊：按照片逐段画出，允许细线变轻或断开；
- 只剩局部可确认片段：画片段，不闭合、不补全、不对称复制；
- 只有弥散锈色、铜绿边界、孔蚀颗粒、反光或随机斑驳：不画；
- 自动边缘、生成式线稿与照片冲突：删除假线，以照片为准；
- 线图交付前逐段回看原图，必须同时检查“锈蚀是否误画”和“锈蚀下纹饰是否漏画”。

### 4.3 圆形密集纹饰器物

按“外圆/真实边界 → 中心 → 同心环带 → 分区 → 重复单元 → 母题细节 → 损伤与不确定处”绘制。中心、四周环带、乳钉/圆钮、沟槽、卷曲或动物性轮廓等都要按照片定位。黑块只表示明确凹陷/断面/阴刻，不表示锈色和照片阴影；点不用于复制锈蚀颗粒。

### 4.4 简笔线描的完成标准

轮廓用少而稳的线完成；纹饰用清楚的外缘、内缘、转折和端部表达；不使用大片灰阶渐变、不堆叠版画噪点、不用材质效果掩盖未知。精细不等于繁琐，必须让缩印后的读者仍能复核纹饰结构。

## 5. 自动化、扫描和数字复制

自动边缘提取、阈值、锐化、图像生成和矢量化只能作为定位底稿。工作顺序为：保留原照片 → 生成草稿 → 回看全尺寸照片 → 删除背景/锈蚀/反光假线 → 补回模糊但可辨纹饰片段 → 核对外轮廓、中心、环带和尺寸 → 再做黑白化和版式。

不要让自动阈值吃掉浅纹饰、细剖面线或断损边界；不要锐化纸张、米格线、报纸文字和反光；不要覆盖原始照片、原始测量表、铅笔稿或母版。最终文件应注明是“实测图”还是“照片证据转译稿/待实物复核”。

## 6. 分材质技法

所有材质都遵循“先测量与投影，再结构，再表面”；材质颜色不能替代形制、剖面和尺寸。

### 陶器、瓷器、陶片

先画中心轴、基线、口沿、肩部、最大腹径、底部/底足、外轮廓、内壁和胎体厚度，再画把手/流口/钮、纹饰带和残损。完整器可用半剖；陶片要记录原器方向、弧度、断口和胎体厚薄。釉色、窑变、泥土和随机斑驳不画成结构线；刻划/压印/模印要保留起止、穿插、叠压和磨损。

### 石器

考虑背面、腹面、侧视、端视和截面；优先画台面、打击点、打击泡、放射线、负疤边界、剥片叠压、修理、刃角、使用磨损和断裂。天然色差、锈状斑驳和随机裂纹不能冒充技术痕迹。必要的排线/黑块须少量、统一光向且不吞掉技术信息。

### 青铜器、铁器和其他金属器

先确认器身分段、口沿、底部、耳/鋬/把/流/钮、铸接/范线、镶嵌、铭文、腐蚀孔和修复。没有 X 光、CT、修复记录或专家证据时，不把腐蚀后的空腔和推定内部结构画成确定实线。**铁锈与铜绿本身不画**；只画其下仍能确认的原始纹饰、孔洞、断口和结构边界，腐蚀情况另行记录。

### 玉器、石雕和磨制石器

重点是平面轮廓、厚度、刃/脊/棱、穿孔入口/出口/孔道、切割、琢磨、抛光、阴刻、阳刻和透雕。沁色、斑纹、透明感和光泽不画成纹饰；天然裂隙不画成阴刻。

### 骨、角、牙、贝器

区分骨干/骨端/髓腔、皮质/松质、纵向纤维、锯切、削磨、穿孔和刻划；端视或剖面通常比单一外轮廓更有信息。点描只在项目需要表达断面孔隙且不与用户硬原则冲突时使用。

### 玻璃、琉璃和透明器

重点是壁厚、口沿、底部、气泡、接缝、模痕、卷边和断口；透明、高光和彩色效果交给照片/文字。残片要区分断口、壁厚变化、风化层和装饰层。

### 木器、漆器、纺织、皮革和其他有机物

木器先画外形、榫卯、孔、接缝、木纹方向和工具痕；漆器区分漆层、胎体、脱落、裂纹和修复；纺织/编织先画经纬、缝合、边缘、折叠和缺失范围。不要把每个色差或显微颗粒都变成结构线。

### 货币、印章、牌饰等平面器物

明确正反面、顶部/12 点方向、边缘、厚度、穿孔、铭文阅读方向和镜像关系。印章的印面与印出文字方向不同；缺笔、磨损、粘附和模糊处按现状记录，不凭字义补字。

## 7. 工具、保护和实测

### 工具

直尺/钢尺用于长度和比例尺；游标卡尺用于口径、厚度、孔径；分规用于转移距离和比较半径；圆规、直角尺、三角板用于几何辅助；弧度规/轮廓规只在不会损伤器物并经允许时使用；放大镜/体视显微镜记录细部、倍率和位置；HB/2H/3H/B 铅笔、可塑橡皮、针管笔/蘸水笔、绘图板、方格纸、描图膜和纸垫用于起稿与墨线。

### 保护底线

脆弱、掉粉、掉釉、带颜料、刚修复或禁止翻转的器物，先按保护方案；不用笔尖、圆规或金属轮廓规压器物；不为看底部擅自翻转；碎屑、铅粉和橡皮屑不吹向器物；原始记录不覆盖。

### 实测顺序

总体尺寸 → 关键结构 → 壁厚/孔道/断面 → 纹饰带宽和重复单元 → 残损/修复边界。关键量至少重复两次；不一致时找原因，不用平均值掩盖误差。用分规转移时先转到纸上再读数，不在器物上反复落点。

## 8. 传统手工与数字交付流程

1. 确认研究目的、项目体例、最终尺寸、比例、视图和是否接触实物；
2. 做安全检查并建立器物证据表；
3. 全方位观察、固定方向并记录照片；
4. 选择最少但完整的视图；
5. 建立中心轴、基线、最大径线、关键高度和外接框；
6. 实测总体尺寸和关键局部，记录偏心、变形、错台、缺失；
7. 轻铅笔先画比例框、外轮廓、内轮廓、器壁和结构；
8. 将关键点投影到其他视图，核对对齐、镜像和厚度；
9. 先画纹饰布局，再逐段画母题；锈蚀下模糊但可辨纹饰照图保留；
10. 第一次审图通过后再墨线：外轮廓/剖面 → 主要结构 → 内轮廓/孔道/接缝 → 纹饰细部 → 剖面线与必要材质线 → 尺寸 →（用户或项目规范要求时）图例；
11. 清稿、扫描、裁切和排版，保留原稿与版本记录；
12. 按最终印刷尺寸检查，并归档测量表、铅笔稿、墨线稿、母版、出版副本和修改记录。

## 9. 交付前审图清单

以下任一“必须退回”项未通过，不进入最终排版：

- 对象编号、方向、测量来源、修复状态可追溯；
- 主视、侧视、顶/底视方向一致，对应点对齐，非对称没有被修圆；
- 总体尺寸、关键尺寸、单位、比例或比例尺可复核，比例尺未被裁切/变形；
- 外轮廓来自器物边界而非阴影；内轮廓、壁厚、孔道、空腔、接缝和附件关系清楚；
- 剖面目的明确，剖面轮廓醒目，剖面线平行等距，不穿空腔、文字和非剖切区域；
- **锈蚀本身、铜绿、反光、背景、颗粒和斑驳没有被画成线图信息；**
- **锈蚀下略有模糊但可辨的纹饰已逐段画出，确实不可辨处没有被补成完整母题；**
- 纹饰单元、位置、方向、疏密、连接、叠压、端部和损伤可核对；表现为清晰精细的简笔线描；
- 没有无来源的镜像、对称补全、类型学补纹或生成式假线；
- 粗/中/细线语义和相对层级统一，最终缩印后细线和小字仍可读；
- 图号、器名、编号、尺寸、比例尺、说明和版本信息齐全；用户或项目规范要求线例时，再核对图例是否齐全且与线型一一对应；
- 原始测量表、照片、铅笔稿、墨线稿和母版未被覆盖。

### 最终 30 秒复核

把图缩到最终阅读尺寸，问：一眼能看出方向吗？器形与结构能分开读吗？哪里残、哪里补、哪里不确定？纹饰是否清楚但没有抢过器形？是否有一条说不清用途的线？尺寸和比例尺可信吗？如果答不上来，状态写“修改”，不写“通过”。

## 10. 30 天练习计划

每天 60—120 分钟，保留实测表、铅笔稿、墨线稿、最终缩印样和自评；练习对象使用教学复制品、普通器物或公开图像，不擅自接触脆弱文物。

| 天数 | 练习 | 目标 |
|---|---|---|
| 1 | 线型字典 | 每条线都能说出用途 |
| 2 | 直线、曲线、转折 | 不抖、不重复描、转折无毛刺 |
| 3 | 主/侧/顶视投影框 | 关键点严格对齐 |
| 4 | 1:1、1:2、1:3、2:1 比例转移 | 分清原稿比例与出版比例 |
| 5 | 管、板、带孔块体截面 | 区分空腔、实体、壁厚 |
| 6 | 45° 平行等距剖面线 | 不穿空腔，缩印不成黑块 |
| 7 | 无材质结构图 | 去掉阴影仍读得懂器形 |
| 8 | 规则完整陶器 | 口径、底径、高、厚度一致 |
| 9 | 变形陶器 | 保留偏心和不规则 |
| 10 | 把手、流口、钮 | 连接、厚度、方向对应 |
| 11 | 陶片方向 | 区分确定、推定、未知方向 |
| 12 | 胎体、断口、釉层 | 结构线与材质线不混 |
| 13 | 带状纹饰布局 | 先带宽/边界，再母题 |
| 14 | 陶器综合图 | 统一比例、线宽和剖面；按要求处理图例 |
| 15 | 石片背/腹/侧视 | 正反面不颠倒 |
| 16 | 剥片疤叠压 | 不把色差/天然裂纹当技术痕 |
| 17 | 修理、刃部、缺口 | 技术信息突出 |
| 18 | 石器开放轮廓/排线/黑块 | 比较最终尺寸可读性 |
| 19 | 金属器形与连接 | 不用黑影遮连接 |
| 20 | 金属工艺痕与腐蚀区分 | 锈蚀本身不画，原始纹饰不漏画 |
| 21 | 有可靠资料的内部结构 | 不把推测画成实线 |
| 22 | 玉石孔道和截面 | 透明感不抢孔道与厚度 |
| 23 | 玉石抛光、砣磨、阴刻、透雕 | 裂隙与颜色不误画成纹饰 |
| 24 | 骨、角、牙器 | 区分骨质结构与加工边界 |
| 25 | 玻璃或木器 | 不用大面积灰阶制造材质 |
| 26 | 币、印章、牌饰 | 正反、顶部和镜像正确 |
| 27 | 主图＋纹饰局部放大/展开图 | 放大图增加信息 |
| 28 | 盲审 | 他人仅凭线图（如有图例再结合图例）读懂图 |
| 29 | 按审图清单重绘 | 只改有证据的问题 |
| 30 | 完整交付图 | 测量表、各稿、比例尺、缩印样齐全；按要求附图例 |

每周按 1—5 分自评：测量比例、投影对应、外轮廓、内部结构、剖面、纹饰布局、材质/技术表现、残损/复原诚实度、线宽统一、缩印可读性；如提供图例，再单独核对图例统一性。若投影对应或诚实度低于 4，不用增加纹理补救，应回到实测与结构起稿。
