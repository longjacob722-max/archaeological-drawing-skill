# 考古器物绘图：规制与样本技法参考

本文件是 `archaeological-artifact-drawing` 的深度参考。需要具体技术条款时读取；只做一般图像分析时不必把全部内容载入。

## 证据层级

证据优先级、样本与推断的边界沿用主 [SKILL.md](../SKILL.md)。本文件只展开 WW/T 0035—2012《田野考古制图》及项目图版中涉及的投影、比例、线型、剖面和误差条款；书本示范与样本版式不能覆盖适用标准或项目要求。

## 1. 投影与视图

- 一般采用正投影，通常采用第三角投影；不使用近大远小、消失点和透视缩短来替代测量图。
- 基本视图关系：主视图居中，俯视图在上，仰视图在下，左视图在左，右视图在右，后视图通常在最右侧。
- 各视图要做到“长（宽）对正、高平齐、宽（长）相等”。
- 视图数量取能够完整表达器物的最少集合。复原示意图可使用透视，但要把它和实测器物图区分开。
- 组图横排、剖面置于主视图下方、正/侧/背连续排列，均可作为项目体例或样本模板；不能脱离项目要求宣称为唯一排法。

## 2. 比例、图幅和标注

- 常用比例序列包括 1:1、2:1、3:1、4:1，以及 1:2、1:3、1:4、1:5、1:10 等；必要时按十倍级数扩展。
- 有可靠尺寸时可按比例绘制；只有透视照片而没有比例尺或已知尺寸时，只能做结构分析/待测绘草图，不能虚报比例。
- 尺寸触发比例尺的硬规则见主 skill；本节补充：若尺寸只可靠对应一个视图，比例尺只加在这个视图下，其他视图标为结构分析/待实测，不伪造统一比例。米格纸或直尺若受透视、零点不明、与器物不在同一平面等影响，不能升级为出版比例尺。
- 器物图通常可在 A4 图幅内完成；图幅仍应由器物大小、比例和细节密度决定。
- 图号、器名、编号、出土单位/地点、尺寸、比例尺和必要说明要统一；用户或项目规范要求提供线例时，图例中的符号、线型和文字必须一一对应，未要求时默认不在成图中提供线例。
- 比例尺应在图下方清楚可读；最终以实际印刷/发表尺寸检查，不只看屏幕缩放。

## 3. 线型、线宽和剖面线

### 线型语义

| 线型 | 主要用途 |
|---|---|
| 粗实线 | 主要外轮廓、剖面轮廓、主要结构分界 |
| 中粗实线 | 图框、内轮廓、次要结构、视图连接线、剖切符号、比例尺线 |
| 细实线 | 尺寸线、引出线、细部线、一般辅助线、剖面线 |
| 虚线 | 不可见轮廓，或必要的修复/复原轮廓 |
| 点划/链线 | 中心线、对称轴、剖切位置和范围 |
| 波浪/断裂线 | 局部复原、自然残断或人工断裂等特殊边界，按适用体例区分 |

### 线宽控制

- 最小线宽约 0.1 mm；一张图控制为约三档线宽，粗—中—细约为 3:2:1。
- 平行线间距一般不小于约 0.7 mm；剖面线、细密纹饰和小字必须在最终输出尺寸仍可辨识。
- 同一张图、同一组图的同类线型要统一。虚线在转角和交叉处要正确衔接；复原轮廓不宜铺满过多虚线。
- 结构线优先于渲染线；光影不能掩盖轮廓、剖面和尺寸信息。

### 剖面线

- 通常使用与截面总体方向约成 45° 的等距平行线。
- 相邻构件可以改变剖面线方向或间距，以区分构件；不能把不同结构画成一片密黑。
- 不要把照片中的自然阴影直接当作剖面线或黑块。

## 4. 剖视图和剖面图

- **剖视图**：假想剖切并移去观察者一侧，画出剩余部分投影后所见的内部结构。
- **剖面图**：只画剖切平面与器物相交的截面形状。
- 剖切形式可为全剖、半剖和局部剖；半剖只适用于对称性已被证实且不会隐藏关键不对称的对象。
- 移出剖面画在视图外，重合剖面画在视图内；剖面轮廓通常较重，内部剖面线较轻。
- 三足器的足与器壁关系复杂，应参照标准附录的剖切组合，不要把普通对称器物的半剖方案直接套用。

## 5. 尺寸误差

WW/T 0035—2012 对器物图相对误差给出“不宜超过 ±1.0%”的控制目标，计算式为 `e=(E/A)×100%`，其中 `A` 为实物真实尺寸，`E` 为测量值与真实值之差。它是总体制图质量目标，不是允许关键结构随意偏差的理由。口沿、底足、孔径、壁厚、榫卯和纹饰边界等关键点应使用更严的控制。

## 6. 按对象组织信息

### 浅腹、不规则器物

先用俯视或主视确定外轮廓、内腔和装饰分区，再用纵剖/横剖表达器壁、内外关系和厚度。坐标点、测量轴线和转折点先于曲线润色。保留偏心、烧制变形、缺口和局部塌陷，不为了图面整齐强行画圆。

### 立体人物或雕塑类器物

选择能解释正面识别特征、侧面厚度/附件前后关系、背面结构的方向视图。每幅图应有明确任务；先统一顶点、底线、底座和关键附件，再画衣褶、帽褶、接缝和浅浮雕。颜色、反光、铜绿、污渍和随机裂纹通常不进入结构线图，除非它们是研究对象。

### 圆形密集纹饰器物

先确定中心、外圆、同心环带和分区，再画中心纹饰、环带纹饰、重复单元、方向、疏密和叠压关系。高低起伏可用清楚的轮廓线、辅助线、极少量明确凹陷黑块和留白转译；黑块不等于照片阴影。**锈蚀、铜绿、斑驳和腐蚀颗粒不画**，但锈蚀覆盖下仍能辨认的纹饰起伏、沟槽、卷曲走向、端部和叠压线必须画出。单幅正投影只有在厚度、背面和结构不构成主要信息缺口时才足够。

### 锈蚀与纹饰的二分转译

这是纹饰重点图的硬判定：

| 照片证据 | 线图处理 |
|---|---|
| 连续的浮雕外缘/内缘、沟槽、刻划线、卷曲方向、纹饰端部、重复或叠压关系，即使被锈蚀覆盖 | 绘出；按案例式简笔线描保持线条干净、转折清楚、细部可核对 |
| 只呈现为弥散色块、颗粒、孔蚀、铜绿边界、随机斑驳或反光高光 | 删除；不点描、不涂黑、不沿斑驳边界描轮廓 |
| 纹饰走向可见但局部断失 | 保留可见段，断开或以不确定标记收尾；不凭常见纹样补齐 |
| 生成式/自动边缘结果与照片不一致 | 以照片为准，删除假线；自动结果只能作定位底稿，不能直接交付 |

纹饰“清晰”不是增加噪点，而是让读图者能复核单元、位置、方向、疏密、连接、叠压和损伤。纹饰“精细”不是把每个锈蚀颗粒都复制，而是准确交代真实的边缘、转折、端部和层次。

### 石器

视图应服务于剥片和加工信息：台面、打击点、打击泡、放射线、同心波纹、负疤、石皮、刃缘修理、断面和疤痕叠压关系。石器图的目标不是只复制外轮廓，而是让人能读取加工方向和技术过程。

## 7. 照片分析协议

1. 查看全尺寸原图，确认方向、镜像、旋转、遮挡和透视。
2. 找比例尺、网格、已知尺寸和多视角共同点；没有这些证据就不报精确尺寸。
3. 先记录可见事实，再记录多视角支持的结构，最后单列未知区域。
4. 对每个成品视图回答“它解决了哪个信息缺口”。
5. 检查成品是否将颜色/阴影误译为结构线，是否把真实不对称改成理想对称。
6. 检查纹饰的单元、方向、密度和连续关系，不只检查“像不像”；逐段确认锈蚀下可辨纹饰已绘出、锈蚀本身已删除，并符合案例式简笔线描。
