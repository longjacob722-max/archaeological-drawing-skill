# 国内网页对照：器物图版补充

本参考用于“先找国内公开器物图版，再独立重绘、并排比较、反推规则”的任务。总硬规则以主 [SKILL.md](../SKILL.md) 为准；本文件只保留国内文物、国内正式资料和网页案例特有的回归检查。

## 1. 使用范围与证据顺序

- 本页只采用中国国内文物，以及中国国内博物馆、文物考古机构、正式考古报告、政府或高校公开资料。
- 资料顺序固定为：实物照片/测量记录 → 正式报告图版和文字 → 国内成品图的表达惯例 → 绘图者推断。
- 国内网页成品只能帮助检查视图、剖面、线宽、比例尺和版式，不能代替照片为器形、纹饰、残损或不对称关系提供证据。
- 原器物照片、发表线图和独立重绘必须按文物名称、图号或标本号配对；不能把不同器物、不同修复状态或不同版本的图版混在一起。

## 3. 国内网页对照时必须分清的三类证据

1. **实物证据**：照片、不同方向、比例尺、米格纸、测量记录和同一标本的共同特征；负责决定轮廓、断口、纹饰单元和真实不对称。
2. **国内图式证据**：国内报告或博物馆成品图怎样安排视图、线宽、剖面、纹饰分带和比例尺；只负责告诉我们如何表达。
3. **推断证据**：完整器复原、被遮挡纹饰、类型学补齐和自动路径；没有独立证据时必须标为未知、复原或待复核，不能升级为实测线。

## 4. 国内案例的强制回归检查

### 4.1 陶片与残器

- 只画保存下来的陶片边界；照片不足以支持完整器形时，不复原整器。
- 口沿、底部、断口和装饰带分开记录；“看起来像连续器形”不是补全理由。
- 每一道水平带、波折带、刻划线或彩绘带都要能在国内照片、拓片或正式图版中找到对应；模糊区域只画能确认的走向和端部。
- 半剖/半外壁必须属于同一个连续轮廓；禁止另画漂浮的剖面条、第二个残片或未证实的复原线。
- 断口不等于阴影；断口内部可用少量剖面线表达厚度，但不得用密集黑块填充。

### 4.2 石器、骨器和其他非陶器

- 先判断国内照片是否真的给出多个面；有两面证据才安排双面，有厚度证据才安排剖面。
- 轮廓、主要剥片疤边界、平台、裂隙、磨损和热损伤分层；表面色差、风化斑和摄影阴影不转成线。
- 视图必须对正，关键特征在不同面之间相互一致；不得为了“整齐”把自然不对称修成对称。
- 不确定的剥片边界、裂隙和使用痕留空或以明确的不确定线表达，不创造新的技术痕迹。

### 4.3 国内网页案例的比例与版式陷阱

- 国内报告图版中的比例尺只适用于原图的尺寸和缩放关系；裁剪、重排或放大后不可把像素长度当实测尺寸。
- 国内图号、说明和组合版式只作表达参考；独立重绘的比例尺与成品状态仍按主 skill 重新核验。
- 图中明确给出可靠尺寸时，按尺寸设置成图比例，并在对应视图下标比例尺；只有网页像素、透视米格纸或零点不明的直尺时，标为结构分析稿。

## 5. 国内网页案例的人工复核闸门

自动化清理和生成式结果只能作底稿。交付前必须删除米格线、标签、数字、流程照中的铅笔辅助线、国内网页背景和摄影假线；确认裁剪没有改变比例判断；逐段回看国内原照片，保留锈蚀下可辨纹饰，删除锈蚀本身、反光和色差；保留原照片、来源链接和未经清理的底稿供复核。
